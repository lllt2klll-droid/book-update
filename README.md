# SGK Teacher Workspace releases

This repository hosts public Windows release downloads and the version manifest used by the app.

- `version.json` describes the latest release and links to the GitHub Releases page.
- `SGK Teacher Workspace Setup <version>.exe` installs the app and creates shortcuts.
- `SGK Teacher Workspace Portable <version>.exe` runs without installation.

The app and its backend run locally. Books and app data are stored on the user's computer. AI and online features require an internet connection and may send selected content to their configured service.
